# CRM Stage 1, PR 0 — UUID Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every domain table from auto-incrementing `bigint` keys to UUID v7 keys, preserving all existing rows, before any new CRM model is written.

**Architecture:** SQLite cannot alter a primary key in place and cannot `ALTER TABLE ADD CONSTRAINT`, so the conversion uses the portable table-rebuild pattern: create the new UUID-keyed table with its foreign keys declared up front, copy every row through an in-memory `id → uuid` map, drop the old table, rename the new one into place. Tables are converted in dependency order — `teams`, then `users`, then everything referencing them — so each new table can reference an already-converted parent. This same code runs unchanged on SQLite, MySQL, and PostgreSQL.

**Tech Stack:** PHP 8.5, Laravel 13, Pest 5, PHPStan (larastan) level 7, Pint, SQLite in development.

## Global Constraints

- PHPStan stays at **level 7**. Do not raise it. (`.ai/rules/general.md`)
- Models carry **exactly one docblock**: `/** @mixin IdeHelperX */`. (`.ai/rules/models.md`)
- `protected $guarded`, never `$fillable`. `#[UseFactory(...)]` + `HasFactory`, never `/** @use HasFactory<...> */`.
- No `@return` docblocks on relation methods.
- Curly braces on all control structures. Explicit return types and parameter type hints everywhere.
- **Model hooks own derived data.** Slugs are generated by `creating` and regenerated by `updating`. Nothing sets a slug by hand.
- **The migration must be portable.** Use `Schema` and `DB` builder methods only. No driver-specific raw SQL, no `ALTER COLUMN`, no `ADD CONSTRAINT` after create.
- **Every foreign key is declared at table-create time.** SQLite cannot add one later.
- Run `vendor/bin/pint --dirty --format agent` before every commit.
- Full gate is `composer test`. Individual runs use `php artisan test --compact --filter=...`.
- **This PR adds no features.** Behaviour before and after is identical; only key types change.

## Scope

| Table | Action | Why |
| --- | --- | --- |
| `teams` | Rebuild with `uuid` primary key | Domain model. No outgoing foreign keys, so it converts first. |
| `users` | Rebuild with `uuid` primary key, `current_team_id` → `foreignUuid` | Domain model, references `teams`. |
| `team_members` | Rebuild; `id`, `team_id`, `user_id` all uuid | Pivot. |
| `team_invitations` | Rebuild; `id`, `team_id`, `invited_by` all uuid | Domain model. |
| `passkeys` | Rebuild; `id`, `user_id` uuid | Domain model (published Fortify migration, editable). |
| `sessions` | Recreated empty with `uuid` `user_id` | Ephemeral. See note below. |
| `password_reset_tokens` | Untouched | Primary key is `email`; no integer keys. |
| `jobs`, `job_batches`, `failed_jobs`, `cache`, `cache_locks` | Untouched | Framework infrastructure, not domain models. |

**`sessions` is recreated rather than migrated.** Its `user_id` must change type, and a
session row is a serialised cookie payload with no independent value. Preserving them
across a key-type change buys nothing; the cost is that everyone is logged out once.
This is called out here so it is a decision rather than a surprise.

### Task 2: The conversion migration

**Files:**
- Create: `database/migrations/2026_08_11_000000_convert_domain_tables_to_uuids.php`

**Interfaces:**
- Consumes: nothing.
- Produces: a schema where `users.id`, `teams.id`, `team_members.id`,
  `team_invitations.id`, and `passkeys.id` are `uuid`, and every reference to them is
  `foreignUuid`.

- [ ] **Step 1: Write the migration**

Read this before typing it: the `uuid()` primary keys are created **without**
`->primary()` on a separate line, because `$table->uuid('id')->primary()` is the only
form SQLite accepts at create time. Foreign keys are declared inside the `create`
closure for the same reason. `Schema::withoutForeignKeyConstraints()` wraps the whole
operation so drops and renames cannot trip a constraint mid-flight.

Create `database/migrations/2026_08_11_000000_convert_domain_tables_to_uuids.php`:

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Schema;
use Illuminate\Support\Str;

return new class extends Migration
{
    /** @var array<string, array<int|string, string>> */
    protected array $maps = [];

    public function up(): void
    {
        Schema::withoutForeignKeyConstraints(function () {
            $this->maps['teams'] = $this->assignUuids('teams');
            $this->maps['users'] = $this->assignUuids('users');

            $this->convertTeams();
            $this->convertUsers();
            $this->convertTeamMembers();
            $this->convertTeamInvitations();
            $this->convertPasskeys();
            $this->convertSessions();
        });
    }

    public function down(): void
    {
        throw new RuntimeException(
            'Converting UUID keys back to auto-incrementing integers is not supported. '
            .'Restore from the pre-conversion database backup instead.'
        );
    }

    /** @return array<int|string, string> */
    protected function assignUuids(string $table): array
    {
        return DB::table($table)
            ->orderBy('id')
            ->pluck('id')
            ->mapWithKeys(fn ($id) => [$id => (string) Str::uuid7()])
            ->all();
    }

    protected function mapped(string $table, int|string|null $id): ?string
    {
        return $id === null ? null : ($this->maps[$table][$id] ?? null);
    }

    protected function convertTeams(): void
    {
        Schema::create('teams_uuid_tmp', function (Blueprint $table) {
            $table->uuid('id')->primary();
            $table->string('name');
            $table->string('slug')->unique();
            $table->boolean('is_personal')->default(false);
            $table->timestamps();
            $table->softDeletes();
        });

        DB::table('teams')->orderBy('id')->each(function (object $team) {
            DB::table('teams_uuid_tmp')->insert([
                'id' => $this->mapped('teams', $team->id),
                'name' => $team->name,
                'slug' => $team->slug,
                'is_personal' => $team->is_personal,
                'created_at' => $team->created_at,
                'updated_at' => $team->updated_at,
                'deleted_at' => $team->deleted_at,
            ]);
        });

        Schema::drop('teams');
        Schema::rename('teams_uuid_tmp', 'teams');
    }

    protected function convertUsers(): void
    {
        Schema::create('users_uuid_tmp', function (Blueprint $table) {
            $table->uuid('id')->primary();
            $table->string('name');
            $table->string('email')->unique();
            $table->timestamp('email_verified_at')->nullable();
            $table->string('password');
            $table->foreignUuid('current_team_id')->nullable()->constrained('teams')->nullOnDelete();
            $table->text('two_factor_secret')->nullable();
            $table->text('two_factor_recovery_codes')->nullable();
            $table->timestamp('two_factor_confirmed_at')->nullable();
            $table->rememberToken();
            $table->timestamps();
        });

        DB::table('users')->orderBy('id')->each(function (object $user) {
            DB::table('users_uuid_tmp')->insert([
                'id' => $this->mapped('users', $user->id),
                'name' => $user->name,
                'email' => $user->email,
                'email_verified_at' => $user->email_verified_at,
                'password' => $user->password,
                'current_team_id' => $this->mapped('teams', $user->current_team_id),
                'two_factor_secret' => $user->two_factor_secret,
                'two_factor_recovery_codes' => $user->two_factor_recovery_codes,
                'two_factor_confirmed_at' => $user->two_factor_confirmed_at,
                'remember_token' => $user->remember_token,
                'created_at' => $user->created_at,
                'updated_at' => $user->updated_at,
            ]);
        });

        Schema::drop('users');
        Schema::rename('users_uuid_tmp', 'users');
    }

    protected function convertTeamMembers(): void
    {
        Schema::create('team_members_uuid_tmp', function (Blueprint $table) {
            $table->uuid('id')->primary();
            $table->foreignUuid('team_id')->constrained()->cascadeOnDelete();
            $table->foreignUuid('user_id')->constrained()->cascadeOnDelete();
            $table->string('role');
            $table->timestamps();

            $table->unique(['team_id', 'user_id']);
        });

        DB::table('team_members')->orderBy('id')->each(function (object $membership) {
            DB::table('team_members_uuid_tmp')->insert([
                'id' => (string) Str::uuid7(),
                'team_id' => $this->mapped('teams', $membership->team_id),
                'user_id' => $this->mapped('users', $membership->user_id),
                'role' => $membership->role,
                'created_at' => $membership->created_at,
                'updated_at' => $membership->updated_at,
            ]);
        });

        Schema::drop('team_members');
        Schema::rename('team_members_uuid_tmp', 'team_members');
    }

    protected function convertTeamInvitations(): void
    {
        Schema::create('team_invitations_uuid_tmp', function (Blueprint $table) {
            $table->uuid('id')->primary();
            $table->string('code', 64)->unique();
            $table->foreignUuid('team_id')->constrained()->cascadeOnDelete();
            $table->string('email');
            $table->string('role');
            $table->foreignUuid('invited_by')->constrained('users')->cascadeOnDelete();
            $table->timestamp('expires_at')->nullable();
            $table->timestamp('accepted_at')->nullable();
            $table->timestamps();
        });

        DB::table('team_invitations')->orderBy('id')->each(function (object $invitation) {
            DB::table('team_invitations_uuid_tmp')->insert([
                'id' => (string) Str::uuid7(),
                'code' => $invitation->code,
                'team_id' => $this->mapped('teams', $invitation->team_id),
                'email' => $invitation->email,
                'role' => $invitation->role,
                'invited_by' => $this->mapped('users', $invitation->invited_by),
                'expires_at' => $invitation->expires_at,
                'accepted_at' => $invitation->accepted_at,
                'created_at' => $invitation->created_at,
                'updated_at' => $invitation->updated_at,
            ]);
        });

        Schema::drop('team_invitations');
        Schema::rename('team_invitations_uuid_tmp', 'team_invitations');
    }

    protected function convertPasskeys(): void
    {
        Schema::create('passkeys_uuid_tmp', function (Blueprint $table) {
            $table->uuid('id')->primary();
            $table->foreignUuid('user_id')->constrained()->cascadeOnDelete();
            $table->string('name');
            $table->string('credential_id')->unique();
            $table->json('credential');
            $table->timestamp('last_used_at')->nullable();
            $table->timestamps();

            $table->index('user_id');
        });

        DB::table('passkeys')->orderBy('id')->each(function (object $passkey) {
            DB::table('passkeys_uuid_tmp')->insert([
                'id' => (string) Str::uuid7(),
                'user_id' => $this->mapped('users', $passkey->user_id),
                'name' => $passkey->name,
                'credential_id' => $passkey->credential_id,
                'credential' => $passkey->credential,
                'last_used_at' => $passkey->last_used_at,
                'created_at' => $passkey->created_at,
                'updated_at' => $passkey->updated_at,
            ]);
        });

        Schema::drop('passkeys');
        Schema::rename('passkeys_uuid_tmp', 'passkeys');
    }

    protected function convertSessions(): void
    {
        Schema::dropIfExists('sessions');

        Schema::create('sessions', function (Blueprint $table) {
            $table->string('id')->primary();
            $table->foreignUuid('user_id')->nullable()->index();
            $table->string('ip_address', 45)->nullable();
            $table->text('user_agent')->nullable();
            $table->longText('payload');
            $table->integer('last_activity')->index();
        });
    }
};
```

> **Why `down()` throws.** A reversible down would have to invent integer keys, and
> anything that referenced the old ones is gone. Throwing is honest; the recovery path
> is the Task 1 backup. State this in the PR description.

> **Why `two_factor_*` columns appear in the new `users` table.** They were added by
> `2025_08_14_170933_add_two_factor_columns_to_users_table.php`, which runs before this
> migration. Rebuilding the table means re-declaring them. **Before running this,
> open that migration and confirm the column names and types match what is written
> above** — if it differs, the rebuild silently drops two-factor data.

## What this PR deliberately does not do

- **No new models.** `Organization` and friends arrive in PR 1, born UUID-native.
- **No `HasUuids` on framework tables.** `jobs`, `cache`, and `sessions` are
  infrastructure. `sessions.user_id` changed type only because it references `users`.
- **No route-key changes.** `Team` still resolves by `slug` and `TeamInvitation` by
  `code`, so no UUID appears in a URL. New models should follow that pattern.

## Notes for the reviewer

- The `id → uuid` maps are held in memory for the duration of the migration. On a
  database with millions of users this would need chunking; at Quill's current scale
  (tens of rows) it is the simplest correct thing, and it keeps the mapping consistent
  across all six tables in one pass.
- `Str::uuid7()` produces time-ordered UUIDs, so index locality is comparable to
  auto-incrementing integers. This is why the plan uses `HasUuids` rather than
  `HasVersion4Uuids`.
- `down()` throwing is intentional and documented above. If a reversible path is ever
  needed, the honest version is a restore, not a migration.
